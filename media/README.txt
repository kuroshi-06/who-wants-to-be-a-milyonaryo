Put your files in this folder with EXACTLY these names:
intro.mp4     - intro video (plays first when the site opens)
bgm.mp3       - background music during questions
question.mp3  - plays before each question appears
lock.mp3      - when an answer is selected (optional)
correct.mp3   - correct answer
wrong.mp3     - wrong answer (optional)
win.mp3       - millionaire win (optional)
start.mp3     - Start button (optional)
Missing files are simply skipped.
